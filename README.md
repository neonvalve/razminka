# Разминка

Бесплатное приложение Windows для перерывов за компьютером: напоминания в трее, упражнения по таймеру и повторениям, выбор постоянной тренировки, свои JSON-файлы и автообновление.

- [Сайт и скриншоты](https://neonvalve.github.io/razminka-releases/)
- [Скачать последнюю версию](https://github.com/neonvalve/razminka-releases/releases/latest)
- [Сообщить об ошибке](https://github.com/neonvalve/razminka-releases/issues)
- [Угостить автора кофе](https://pay.cloudtips.ru/p/019480d0)

Windows 10 / 11 x64. `Setup-x64.exe` — установщик; `Portable-x64.zip` — распаковать и запустить `Razminka.exe`. Файл `Update-x64.zip` используется приложением для самообновления, скачивать его вручную не нужно. Контрольные суммы — в `SHA256SUMS.txt`.

Тренировки выбираются в настройках. В комплекте: короткая разминка и чередование 10 отжиманий → 10 приседаний → 15 отжиманий → 15 приседаний. Добавляйте свои JSON-файлы в папку `workouts` рядом с приложением.

Начиная с версии 1.2 обновления загружаются автоматически и устанавливаются после подтверждения. Автоматическую проверку можно отключить. Настройки и пользовательские тренировки сохраняются. Версии 1.0–1.1 нужно один раз обновить вручную.

Этот репозиторий содержит сайт и готовые релизы. Исходный код приложения хранится отдельно в закрытом репозитории.
