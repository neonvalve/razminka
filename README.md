# Разминка

Небольшая бесплатная программа для Windows, которая напоминает сделать перерыв за компьютером и помогает провести разминку.

Вы задаёте интервал, часы напоминаний и выбираете тренировку. Когда приходит время, программа предлагает встать из-за стола. Напоминание можно отложить или пропустить. Если вы надолго отошли, заблокировали экран или отправили компьютер в сон, отсчёт начинается заново.

Упражнения бывают по таймеру и на количество повторений. В комплекте есть короткая разминка и чередование отжиманий с приседаниями: сначала по 10 раз, затем по 15. Свои тренировки можно собрать прямо в настройках: добавить упражнения, выбрать время или повторения, изменить порядок и отдых. Формат файлов знать не нужно. Название тренировки тоже можно изменить. В настройках есть светлая, тёмная и системная темы; выбранное оформление применяется ко всем окнам без перезапуска.

## История тренировок

В меню трея и настройках есть история. Она хранит дату, результат и упражнения каждой тренировки, план и подтверждённые повторения, время работы, подготовки и пауз. Перед кнопкой «Готово» можно изменить фактически выполненное количество. Все записи остаются на компьютере и сохраняются при обновлении. История начинается с версии 1.2.8.

## Как установить

Нужна Windows 10 или 11, 64 бита. Выберите Setup-x64.exe для обычной установки либо Portable-x64.zip для запуска без установки. Переносимую версию нужно полностью распаковать и открыть Razminka.exe. Необходимые библиотеки уже включены.

## Обновления

Начиная с версии 1.2 программа проверяет новые выпуски после запуска и каждые шесть часов. Она скачивает пакет, проверяет SHA-256 и предлагает установить его с перезапуском. В меню трея есть ручная проверка, а автоматическую можно отключить в настройках. С версий 1.0 и 1.1 нужно один раз обновиться вручную.

Файл Update-x64.zip используется самим приложением. Для ручной установки выбирайте Setup или Portable.

Регистрация не нужна. Настройки, тренировки и счётчики хранятся на компьютере. Здесь находятся сайт и готовые выпуски; исходники хранятся отдельно в закрытом репозитории.
